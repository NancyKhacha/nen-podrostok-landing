# Лендинг курса «У меня подросток, помогите»

## Исправления после публикации, 16.10.2026

Перенесены проверенные исправления с n-e-n.ru: новый дизайн, иллюстрации, цены и тексты программы сохранены. Белые подписи кнопок имеют контраст 4,96:1 (при наведении 4,64:1). Яндекс Метрика сохраняет существующие счетчики и цели; возвращен резервный no-JS пиксель Школы. Рекламные UTM, yclid, gclid, vk_click_id и promo передаются в разрешенные ссылки, посторонние параметры не копируются.

Шрифты Unbounded и Golos Text находятся в `images/` в формате WOFF2 вместе с лицензиями OFL; символы и диапазоны веса сохранены. Их общий размер — 336 576 байт вместо 962 564 байт TTF. GitHub Pages и локальный сервер используют относительные пути, поэтому репозиторий работает самостоятельно. На домене `n-e-n.ru` ранний скрипт выбирает общие ресурсы `/school/images/nen-*.woff2`. При выкладке копируйте **index.html и images/**; для подросткового курса общие файлы также должны быть выложены из репозитория Школы в `/school/images/`. Без JavaScript используются локальные копии шрифтов из images.

Проверены реальные браузерные сценарии на 1440/703/390/320px: контраст, загрузка шрифтов и изображений, FAQ с клавиатуры, состояние плавающей плашки, старые fragment-ссылки, передача параметров и отсутствие ошибок JavaScript. Реальные банковские платежи не выполнялись.

Рядом с ценой и в FAQ явно описаны аудиоверсии всех 33 уроков, 33 памятки для скачивания/печати и квизы с объяснениями (44 вопроса в практических уроках). Исправлен контраст синей карточки примера. Старые `#program`, `#format`, `#price`, `#situations`, `#purchase-after-benefits`, `#main`, `#hdr` и `#module-1`…`#module-9` работают; модуль раскрывается при прямом входе и смене hash. Событие `buy_click` отправляется один раз с параметром `placement=hero|price|sticky`, согласованно в dataLayer и цели Метрики.

## Исходный контекст

Продающая страница курса Школы НЭН для родителей подростков 11–17 лет. Один файл `index.html` без сборки, стили и скрипт внутри. Токены, кнопки, шапка и подвал взяты с лендинга [n-e-n.ru/perestan](https://n-e-n.ru/perestan/) и макета Figma «NEN products» (node 111:6232).

Структура: первый экран → программа (9 разделов, 33 урока) → как устроен урок → авторы и проверка → стоимость → вопросы → подвал с бесплатной помощью. Плашка с покупкой появляется, когда кнопка первого экрана ушла вверх, и прячется на блоке стоимости.

## Что сверить перед выкладкой

Тексты — по ТЗ маркетолога (16.10.2026), «ё» заменена на «е» по стилю НЭН. На мобильном иллюстрация стоит над заголовком (решение Анастасии, вместо «сначала текст» из ТЗ).

1. Адрес страницы, ссылка на оплату `https://n-e-n.ru/course/podrostok/enroll/` и справка «Куда звонить?» — с действующей страницы n-e-n.ru/podrostok/landing/.
2. Ответы об оплате и доступе в «А если…» (промокод на странице оформления, бессрочный доступ без подписки) — оттуда же. Продуктовой команде подтвердить.
3. Блок «Кто работал над материалами»: нужны подтвержденные имена специалистов, специализация и роль (автор, консультант, рецензент). Шаблон строки — в комментарии в коде. Балансити указан соавтором курса.
4. Фрагменты урока в «Откройте то, что нужно сегодня» — дословно из урока «Сколько можно сидеть в телефоне!»; согласовать с редакцией. Скриншоты курса — со старого лендинга (урок «Мы же договаривались!»).
5. `images/hero.png` — обложка НЭН к статье «Как общаться с подростком, чтобы сохранить доверие» (13.03.2025), переведенная в черно-белый контур без фона и перекомпонованная в квадрат.
6. Кнопки покупки — белый на более темном оранжевом #CC3D04 (контраст 4,96:1); фирменный #FB6326 сохранен в акцентах. Кнопка «Личный кабинет» в шапке меньше логотипа.
7. В шапке логотип Школы НЭН (`images/logo-school.svg`, ссылка на n-e-n.ru/school/), в подвале остался логотип издания.

Яндекс Метрика подключена как на /perestan/ и включается только на домене n-e-n.ru.
