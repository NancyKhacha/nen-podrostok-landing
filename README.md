# Лендинг курса «У меня подросток, помогите»

Продающая страница курса Школы НЭН для родителей подростков 11–17 лет. Один файл `index.html` без сборки, стили и скрипт внутри. Токены, кнопки, шапка и подвал взяты с лендинга [n-e-n.ru/perestan](https://n-e-n.ru/perestan/) и макета Figma «NEN products» (node 111:6232).

Структура: первый экран → программа (9 разделов, 33 урока) → как устроен урок → авторы и проверка → стоимость → вопросы → подвал с бесплатной помощью. Плашка с покупкой появляется, когда кнопка первого экрана ушла вверх, и прячется на блоке стоимости.

## Как посмотреть

```bash
python3 -m http.server 8765
```

Затем открыть http://localhost:8765.

## Что сверить перед выкладкой

1. Адрес страницы и ссылка на оплату `/course/podrostok/enroll/` взяты с действующей страницы n-e-n.ru/podrostok/landing/.
2. Состав курса (аудиоверсии, квизы на 44 вопроса, памятки для скачивания, библиотека подсказок), промокод на странице оформления и справка «Куда звонить?» — тоже оттуда. Обещание бесплатных обновлений и скидка Балансити — по плану главной, размер скидки не указан.
3. «Самый полный курс НЭН» в первом экране: по закону о рекламе превосходная степень требует понятного критерия. Здесь сравнение внутри курсов НЭН, юристу стоит взглянуть.
4. Курс подан как совместный с Балансити (метка «НЭН × Балансити» в первом экране, блок авторов, подвал). Фраза об одобрении психиатром, психологом, юристом и врачом — как на старом лендинге. Имена экспертов можно добавить по шаблону в комментарии блока авторов.
5. `images/hero.png` — временная картинка: обложка НЭН к статье «Как общаться с подростком, чтобы сохранить доверие» (13.03.2025), переведенная в черно-белый контур без фона и перекомпонованная в квадрат. `images/course-*.png` — скриншоты курса со старого лендинга.

Яндекс Метрика подключена как на /perestan/ и включается только на домене n-e-n.ru.
