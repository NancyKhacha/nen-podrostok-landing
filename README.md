# Лендинг курса «У меня подросток, помогите»

Продающая страница курса Школы НЭН для родителей подростков 11–17 лет. Один файл `index.html` без сборки, стили и скрипт внутри. Токены, кнопки, шапка и подвал взяты с лендинга [n-e-n.ru/perestan](https://n-e-n.ru/perestan/) и макета Figma «NEN products» (node 111:6232).

Структура: первый экран → программа (9 разделов, 33 урока) → как устроен урок → авторы и проверка → стоимость → вопросы → подвал с бесплатной помощью. Плашка с покупкой появляется, когда кнопка первого экрана ушла вверх, и прячется на блоке стоимости.

## Как посмотреть

```bash
python3 -m http.server 8765
```

Затем открыть http://localhost:8765.

## Что сверить перед выкладкой

1. Ссылка на оплату `/course/podrostok/enroll/` (три кнопки) и адрес страницы в `canonical` и `og:url`: slug рабочий.
2. Условия доступа скопированы с /perestan/: ЮKassa и СБП, бессрочный доступ, кабинет создается сам. Обещание бесплатных обновлений и скидка Балансити — по плану главной, размер скидки не указан.
3. В вопросах написано, что уроки текстовые. Если будет аудиоверсия, поправить ответ.
4. Эксперты: в блоке «Курс написала редакция НЭН» в коде есть закомментированная строка-шаблон. Добавлять после подтверждения редакцией.
5. `images/hero.png` — временная картинка: фрагмент обложки НЭН к статье «Как общаться с подростком, чтобы сохранить доверие» (13.03.2025), переведенный в черно-белый контур без фона.

Яндекс Метрика подключена как на /perestan/ и включается только на домене n-e-n.ru.
